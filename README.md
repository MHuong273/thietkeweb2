## 🚀 Hướng dẫn Chạy ứng dụng Lập trình Web

### 1. Khởi chạy với PHP Built-in Web Server
Mở terminal tại thư mục dự án `D:\web_B1_practice` và chạy lệnh:

```bash
php -S localhost:8000
```

### 2. Truy cập ứng dụng
- Trang giới thiệu cá nhân (`about.php`): [http://localhost:8000/about.php](http://localhost:8000/about.php)
- Bài thực hành Buổi 1: [http://localhost:8000/buoi-01/index.php](http://localhost:8000/buoi-01/index.php)
